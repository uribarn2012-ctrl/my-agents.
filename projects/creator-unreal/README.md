# Creator (Unreal Engine 5.8)

C++ project for the Unreal version of the game. Plan: `../creator/UNREAL-PLAN.md`.

## Important: always open and build through the English path

Unreal's build system corrupts the Hebrew letters in the repo folder name, and the compile fails.
Use this link, which points at this same folder:

    C:\Users\User\UEProjects\Creator\Creator.uproject

If the link is missing (new computer), create it in PowerShell, changing the target if the repo is elsewhere:

    New-Item -ItemType Junction -Path C:\Users\User\UEProjects\Creator -Target "C:\Users\User\סוכנים\projects\creator-unreal"

Build the editor module:

    & "C:\Program Files\Epic Games\UE_5.8\Engine\Build\BatchFiles\Build.bat" CreatorEditor Win64 Development "-Project=C:\Users\User\UEProjects\Creator\Creator.uproject" -WaitMutex

## Planet view

The game starts straight into a procedural planet seen from space (game mode `PlanetGameMode`,
code in `Source/Creator/Planet/`). Every seed gives a different world: continents, oceans with
depth colour and sun glint, mountains, deserts, forests and grassland, polar ice, a cloud layer
with cloud shadows, Unreal's sky atmosphere (blue rim at the edge) and a starry background.

Open it through the English path only:

    "C:\Program Files\Epic Games\UE_5.8\Engine\Binaries\Win64\UnrealEditor.exe" C:\Users\User\UEProjects\Creator\Creator.uproject -game -windowed -ResX=1600 -ResY=900

Controls:

| Input | Action |
|---|---|
| Left mouse drag | Rotate the planet (orbit) |
| Right mouse drag | Turn the view |
| Mouse wheel | Zoom smoothly from space down to about 400 m above the ground |
| N | Generate a new random planet |

Start options (add to the command line):

| Option | Meaning |
|---|---|
| `-CreatorSeed=7` | Use this world seed instead of a random one |
| `-CreatorZoom=far` / `mid` / `near` | Start on the whole globe, a sunlit continent, or mountains by the sea |
| `-CreatorLat=` `-CreatorLon=` `-CreatorAltKm=` | Start over this latitude/longitude at this height |
| `-CreatorShot=C:\path\shot.png` | Wait until the view has finished loading, save a 1600x900 screenshot and quit |
| `-CreatorWait=4` | Seconds to wait after loading before the screenshot (default 8) |
| `-CreatorNoHud` | Hide the bottom text line |
| `-CreatorNoClouds` | Hide the cloud layer |
| `-CreatorNoStars`, `-CreatorNoSkyLight` | Debug: hide the star background or the sky light |

Known limit: close to the ground (below about 100 km) the terrain is still plain: fine relief is a
noise bump pattern, and at some spots chunks of ground are missing or show a straight seam.

Example, the screenshots in `screenshots/` were made like this:

    UnrealEditor.exe C:\Users\User\UEProjects\Creator\Creator.uproject -game -windowed -ResX=1600 -ResY=900 -CreatorSeed=1 -CreatorZoom=far -CreatorNoHud -CreatorShot=C:\Users\User\UEProjects\Creator\screenshots\planet-seed1-space.png

The planet materials are generated by `Scripts/build_planet_assets.py` (run it with
`UnrealEditor-Cmd.exe <uproject> -run=pythonscript -script=<path>` after changing shader code there).

## Owner's decision: IQ is a setting

People are not geniuses by default. Average IQ is a number the player picks for each world (default 100, ordinary people). IQ 200, the "what if everyone was a genius" idea, is only the high end of that option.

## Owner's decisions: customization and inventions

- As many world options as possible are chosen by the player.
- Following real history (real cities at year 0, real disasters) is an option and never the default.
- The real-history start year is selectable. Its default is the earliest date when cities are known for certain, and it includes only well-established facts.
- Every person can have their own destiny, emerging from their traits and circumstances (a knight who becomes king, someone who becomes a holy figure), as realistically as possible. This matters very much to the owner.
- The invention tree is open-ended: peoples can invent things not in it, even beyond what is possible today (for example living inside a computer), and each one is added to the tree.
- Inventions must be credible next steps from what a people knows, never nonsense such as an apple on a stick becoming a weapon.

## Civilization engine

The history simulation lives in `Source/Creator/Civ/` (plain C++, no rendering; the only Unreal object is the test commandlet). It runs a whole world headless: peoples, inventions (a fixed tree of 73 plus new ones invented during play), wars, natural disasters, cities, and named individuals whose lives emerge year by year from their traits and circumstances.

Run the full test (about 30 seconds; writes the samples and `test-report.txt`):

    & "C:\Program Files\Epic Games\UE_5.8\Engine\Binaries\Win64\UnrealEditor-Cmd.exe" C:\Users\User\UEProjects\Creator\Creator.uproject -run=CivHistory -nullrhi -unattended -nosplash

Every check is logged under `LogCivHistory` as PASS or FAIL, ending with a `RESULT:` line. Options: `-Out=<folder>` (default `samples/`), `-Seeds=8`, `-MaxLow=12000` (years for the IQ 100 and 80 runs), `-TuneOnly` (only the IQ table), and tuning overrides such as `-BirthExp=4.8 -SpreadExp=2.5`.

Samples in `samples/`:

| File | What it is |
|---|---|
| `history-sample.txt` | History book of an ordinary world (IQ 100), up to a few centuries after the Moon landing |
| `history-sample-iq200.txt` | The same seed with average IQ 200 |
| `history-sample-real-earliest.txt` | Real history on, starting at the earliest certain city (Uruk, 3200 BCE) |
| `history-sample-real-year0.txt` | Real history on, starting at year 0 |
| `generated-inventions.txt` | Every new invention of the two sample worlds, with parents, need, mechanism, materials and effect |
| `life-stories.txt` | 20 lives from one world: mostly ordinary or failed, a few remarkable |
| `test-report.txt` | The full test log |

Main world settings (`FCivWorldSettings`): seed, average IQ (about 70 to 200, default 100), number of peoples, start era, disaster frequency and strength, war tendency, invention speed, knowledge spread, resources, land fertility, generated and speculative inventions on/off, and real history (real cities and real disasters are separate switches, both off by default; start year defaults to the earliest certain city). Developer tuning constants are in `FCivTuning`.

What IQ does (8 seeds each): IQ 200 reaches the Moon around year 800 (mean 813). IQ 100 moves at about the pace of real history: first city around year 600, writing about 370 years later, printing about 4,100 years after the first city, then steam, electricity and computers in quick succession, and the Moon about 5,700 years after the first city (real humanity: about 5,500). IQ 80 builds cities much later, never reaches printing and never reaches the Moon within 12,000 years. How strongly IQ matters is set per era (`BirthIQExponentByEra`): early breakthroughs depend on rare minds, later ones on schools and institutions.

God actions: speed up, slow or pause time; inspire a people; send a disaster or a miracle; bless, curse or inspire one person; bring anyone out of the crowd as a full person with a consistent past. Worlds save and load exactly, and the same seed always gives the same history.
